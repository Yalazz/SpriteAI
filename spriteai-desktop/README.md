# Sprite AI - Desktop Editor

C++20 + Qt6 + Vulkan kullanan masaüstü editör iskeleti.

Kurulum için:

```bash
cd spriteai-desktop
mkdir build && cd build
cmake .. -DCMAKE_PREFIX_PATH="/Users/emrebilici/Qt/6.x.x/macos"
cmake --build .
./spriteai-desktop.app/Contents/MacOS/spriteai-desktop   # macOS için örnek
```
